# Positive list of the deb for Ubuntu 26.04 (contract rust/spec/paket, part A, "Positivliste und Ausschlussliste").
# One line per file: <kind> <target> <source>. Everything the package holds stands here by name.
# `rust/paket.sh deb --geruest` leaves out a line whose source is not in the tree yet and names it in the build report;
# without `--geruest` a missing source stops the build (paket.quelle_fehlt).
#
# werkbank-lauf-kind (crate lauf, src/bin/kind.rs): the trampoline of werkbank-lauf; without it lauf starts no child.
# werkbank-lauf, werkbank-lauf-kind and werkbank-ordnermarke run outside the enclosure and without a profile: they are dynamic, linked against the OpenSSL of
# the distribution (Depends from dpkg-shlibdeps, libssl3t64). Only what runs in the enclosure or under the profile of the starter is static (referenz.STATISCH).
# werkbank-ordnermarke (crate lauf, src/bin/ordnermarke.rs): a mandatory file of the manifest (decision of the package owner, 21.11.2026).
# werkbank-ca-zulassung (shell script, root): the explicit step that sets `ca_zulassung` of lauf.json without a question (contract, "Zulassung der CA").
# /etc/werkbank/lauf.json is not in this list: postinst writes it for the user (contract, "lauf.json").
#
# werkbank-anmelden (crate anmelden): the sign-in of the route `copilot`; it writes anmeldung.copilot into the store of the holder in the home
# and makes missing levels itself (postinst makes nothing in the home).
# werkbank-halter (crate halter) and its user unit wb-halter.service (addendum holder): the holder keeps anmeldung.copilot and answers the
# model path.
#
# The enclosure (decision V1, 20.11.2026): only the fixed starter werkbank-einschluss carries the AppArmor profile
# (usr.lib.werkbank.werkbank-einschluss). werkbank-lauf has NO profile, so no profile line names its path. No profile of
# this package is `unconfined`; the build stops on it (paket.profil_unconfined).
#
# Supplier of the parts that are not in the tree yet (state 20.11.2026):
#   werkbank-kern, werkbank-lauf (crate lauf), such-mcp, werkbank-einschluss (the starter; crate einschluss),
#   werkbank-modellweg (crate modellweg), the runner of the trial (werkbank-probelauf, drehbuch.py, drehbuchlib, konfig).
# test_werkbank_probelauf.py of the runner is never in the package (exclusion list).
