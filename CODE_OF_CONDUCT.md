# Code of Conduct

This project is a place for technical work. Everyone who takes part, in issues, pull requests
and discussions, is expected to:

- be respectful and stay on the subject;
- criticize code and ideas, not people;
- accept that the maintainer decides what is taken over and what is not.

Harassment, insults, discrimination and publishing other people's private information are not
acceptable.

The maintainer may edit or remove comments, close issues, discussions and pull requests, and
block accounts that break these rules, without prior notice.

To report a problem, write to **licensing@prontea.de** with the subject "Conduct". Reports are
treated confidentially.

# Verhaltenskodex

Dieses Projekt ist ein Ort für technische Arbeit. Von allen, die in Issues, Pull Requests und
Diskussionen mitwirken, wird erwartet:

- respektvoll zu bleiben und beim Thema zu bleiben;
- Code und Ideen zu kritisieren, nicht Menschen;
- zu akzeptieren, dass der Maintainer entscheidet, was übernommen wird und was nicht.

Belästigung, Beleidigung, Diskriminierung und das Veröffentlichen privater Angaben anderer
Menschen sind nicht akzeptabel.

Der Maintainer darf Kommentare bearbeiten oder entfernen, Issues, Diskussionen und Pull Requests
schließen und Konten sperren, die gegen diese Regeln verstoßen, ohne vorherige Ankündigung.

Ein Problem melden Sie per E-Mail an **licensing@prontea.de** mit dem Betreff „Conduct“.
Meldungen werden vertraulich behandelt.
